# RapidEditor 平板版欢迎

欢迎使用 **RapidEditor Android 平板版**！这个文件就是一篇 Markdown，右侧是实时预览。

## 快速上手

- **触摸操作**：单击等于鼠标左键，长按等于右键，双指拖动可以滚动内容。
- **外接键鼠（Dex / PC 模式）**：无需任何设置，插入键鼠后直接像桌面版一样使用——
  `Ctrl+S` 保存、`Ctrl+N` 新建标签页、`Ctrl+W` 关闭标签页、`Ctrl+Shift+T` 恢复刚关闭的标签。
- **打开文件**：通过左侧"目录"面板浏览应用文档目录。
- **保存位置**：文档保存在应用私有目录 `files/docs/` 中，卸载应用才会删除。

## 预览支持

| 文件类型 | 预览方式 |
|---|---|
| Markdown | 应用内实时渲染 |
| LaTeX | 需要外部 TeX 引擎（平板上暂不可用） |
| PDF | 需要外部工具（平板上暂不可用） |
| HTML | 系统浏览器打开（内建本地 HTTP 服务器） |

## 关于这个版本

这是 RapidEditor 的首个 Android 移植：同一份 C99 核心，通过 SDL2 运行在
NativeActivity 上，与 Windows（MSVC + WebView2）、macOS（Cocoa + WKWebView）、
Linux（X11 + WebKitGTK）共享全部编辑器代码。
